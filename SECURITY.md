# 🛡️ Security Policy

## 📌 Supported Versions

Kami secara aktif memberikan pembaruan keamanan untuk versi berikut:

| Version | Status Dukungan     | Catatan                                |
| ------- | ------------------ | -------------------------------------- |
| 5.1.x   | ✅ Didukung        | Menerima semua pembaruan keamanan.    |
| 5.0.x   | ❌ Tidak Didukung  | Harap tingkatkan ke versi terbaru.    |
| 4.0.x   | ✅ Didukung        | Hanya menerima perbaikan kritis.      |
| < 4.0   | ❌ Tidak Didukung  | Disarankan untuk diperbarui.          |

### Catatan  
- **Versi LTS (Long Term Support)** mendapatkan perbaikan keamanan hingga 2 tahun setelah rilis utama.  
- **Versi Non-LTS** mendapatkan perbaikan keamanan hanya selama 6 bulan setelah rilis terbaru.  

## 🚨 Reporting a Vulnerability

Jika Anda menemukan kerentanan dalam proyek ini, harap segera laporkan dengan langkah berikut:

1. Kirim laporan melalui **[GitHub Security Advisories](https://github.com/YOUR-REPO/security/advisories)** atau email ke **security@yourproject.com**.  
2. Sertakan informasi berikut dalam laporan Anda:  
   - **Deskripsi masalah:** Jelaskan kerentanan secara rinci.  
   - **Langkah reproduksi:** Berikan langkah-langkah untuk mereplikasi masalah.  
   - **Dampak:** Jelaskan bagaimana masalah ini dapat dieksploitasi.  
   - **Saran perbaikan (jika ada):** Jika Anda punya solusi potensial, harap disertakan.  

### 🔄 Timeline Respons  
- **Konfirmasi penerimaan laporan:** Dalam waktu 48 jam.  
- **Analisis & penilaian risiko:** 3-7 hari kerja.  
- **Patch & pembaruan:** Bergantung pada kompleksitas masalah (biasanya 7-30 hari).  

Kami berterima kasih atas kontribusi Anda dalam menjaga keamanan proyek ini! 🚀
